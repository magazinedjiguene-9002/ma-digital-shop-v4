Ajouter / modifier un produit

Cette administration reste volontairement locale : les modifications sont enregistrées dans le navigateur (localStorage) de cet appareil, et s'appliquent directement à la boutique publique (index.html). Le code d'accès protège l'affichage de cette page dans ce navigateur ; pour une vraie protection côté serveur, il faudra plus tard un backend avec authentification.

Formats acceptés : PNG, JPG/JPEG, WEBP, GIF. L'image est redimensionnée automatiquement et enregistrée avec le produit.
